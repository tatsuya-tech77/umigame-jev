## 1. コンセプト

**ウミガメのスープを、最新のAIより少ない質問で解けるかを競うブラウザゲーム。**
出題者は文章を生成しない判定専用AI「Jev」なので、人間とAIを同じ出題者・同じルールで比べられる。

- 一言で：「**あなたは何回で解ける？ GPT-6 は14回かかった**」
- 誰に：謎解き・クイズ好き（スマホ）、「AIに勝てる？」を試したい人、エンジニア
- 差別化：先行（Qiita tetsuro731、GitHub sagochiko、Zenn gema、Steam『みんなでウミガメのスープ』ほか）は「出題者を作った」「AIどうしを戦わせた」まで。こちらは**人が遊んでAIと勝負できるゲーム**

## 2. 体験の流れ

1. トップ：「**AIより少ない質問で解けるか？**」
2. **遊び方30秒**（はい／いいえで答えられる質問をして、真相を当てる。例つき）
3. **はじめての3問**（全員共通）：★1 → ★1 → ★2
4. 1問ごとに結果：**AIとの勝ち負け**、真相、カギになった考え方 → シェア。1問で帰っても楽しかった状態に
5. 3問でレーティングと称号（暫定）
6. その後は**レベル（★1〜★5）別の一覧**から選ぶ。問題が増えたらレベル内でランダムに
7. また来る理由：称号を上げる、**新しい問題の追加**（まとめて追加して X で告知）
8. 解けなかった人：真相と「AIもこの問題は3回中1回落とした」などを見せ、シェアもできる

## 3. ルール（人間とAIで揃える）

| 項目 | ルール |
|---|---|
| 質問 | 最大20回（2026-09-26 に40回→15回→20回。15回の上限で測ると Opus でも★4に14手かかったので、人間に余裕を持たせる） |
| 解答 | 最大3回 |
| 数えないもの | 「どちらとも言えません」、質問になっていない入力（ただし合わせて10回まで。費用と、あいまいな質問で探る抜け道のため） |
| 「どちらとも」が2回続いたら | 言い換えの例を出す |
| **今の答え、変かも？** | プレイ中に押せる。その質問を言い換えて Jev に聞き直し、それでも割れたら「どちらとも言えません」に差し替えて回数から外す。記録して、あとで問題を直す |
| 到達度メーター | ★1〜2は出さない。★3以上は「遠い／近い／あと少し／そろった」の4段階、数える質問3回ごとに更新。「そろった」は要点が全部突き止められた状態。AI にも同じものを見せる |
| ヒント | 人間だけ。弱い／強い。**ポイントを下げる**（5節） |
| 質問の候補 | 人間だけ。どの問題にも使える型（「人物について」など）のみ。問題ごとの候補は出さない（ヒントと区別がつかなくなるため） |
| Jev が自信のない答え | 「どちらとも言えません。言い換えてみてください」 |

## 4. AI との勝負

- AI は3体：フラッグシップ2体＋安いモデル1体。各問題3回ずつ（公開前に1回だけ測る）
- **比べる数**：質問数＋外した解答×2（人もAIも同じ数え方。「どちらとも」は数えない）
- AI が解けなかった回は「無限」として、3回の**中央値**を取る
- **勝ち負け**：人の数が AI の中央値より少なければ勝ち、同じなら引き分け、多ければ負け。人もAIも解けなければ引き分け
- **ヒントを使った場合**：勝ち負けは同じように付けるが、「💡ヒントあり」と表示する（シェアにも付く）
- 候補を並べた解答は、外れ1回として数える
- 2回目のプレイは練習扱い（勝ち負けとポイントを付けない）。最初の質問を送った時点で1回目
- AI の名前はランクや称号に使わない。モデル名・測定日・回数を添えて事実だけ。「各社の商標。各社とは無関係です」。「強いAI」「軽いAI」の一言を添える
- **Claude が下書きした問題は Claude に有利かもしれない**ことを明記
- 看板の「最新AIが全滅した1問」は、AI 対戦で自然に出てきたら使う。出すなら作者以外の2人に解いてもらってから
- 「ベンチマーク」とは名乗らない

## 5. ポイント（レーティング）と称号

結果画面では1行、シェアでは2行目以下。主役は4節の勝ち負け。

- 期待値 E = 1/(1+10^((Rq−Rp)/400))。Rp＝遊ぶ人、Rq＝問題（Rp±400 に丸める）
- q ＝ 質問数＋外した解答×2（4節と同じ数）
- 解けたとき s = clamp(0.75 + 0.25×(目標−q)/目標, 0.5, 1)
  - **ヒント：弱いヒント ×0.85、強いヒント ×0.7**（ポイントを下げる）
  - ★4〜5を q < 目標/4 で解いた（まぐれ）：s は0.85まで
- 解けなかった：s = 0
- AI に1体以上勝った問題では、ポイントは下がらない（勝ったのに下がる、を防ぐ）
- 上限：Rp ≥ Rq＋150 の問題では上がらない（簡単な問題だけで稼げない）
- K：10問まで40、以降24
- 初期値：最初に遊んだ3問の成績から（各問の Rq＋400·log10(s/(1−s)) の平均。s は0.09〜0.91に丸め、初期値は最大1,399）
- 表示：1〜2問目は「あと○問でポイントが出ます」、10問までは「暫定」
- 問題のレーティングは公開中は固定
- 記録は端末ごと（消せばやり直せる）。ランキングは作らない

## 6. 結果画面

最初の3つ：
1. 解決／失敗と回数（目標との差）
2. AI との勝負（「GPT-6 に勝ち（7回 vs 14回）」＋ほかの2体）
3. 真相とカギになった考え方

その下に小さく：ポイントと称号、シェア、次の問題、「この答えはおかしい」。
折りたたみ：自分の質問と答えの振り返り、かかった時間。

## 7. シェア

勝ったとき：
```
🐢 GPT-6 に勝った（7回 vs 14回）
★3「窓を割られてお礼を言った女。なぜ？」ヒントなし
🟩⬛⬜🟩⬛🟩🟩
あなたは何回で解ける？ #ウミガメ人間vsAI
https://…/p/window
```
負けたとき：
```
🐢 Claude に負けた（9回 vs 5回）💡ヒントあり
★2「毎日3時に目覚ましをかける男。なぜ？」
人類代表を求む #ウミガメ人間vsAI
https://…/p/alarm
```
- 絵文字は質問ごとの答えの道のり（🟩はい、⬛いいえ、⬜関係ない）。ネタバレにならない
- 勝った相手のうち一番強いAIを先頭に。全敗なら一番差が小さいAI
- 称号は「5段階中4」以上のときだけシェアに入れる
- URL は問題ごと（開いた人がその問題から始められる）
- 共有画像は全体で1枚（問題ごとの画像は公開後）
- ハッシュタグは X で使われていないか確認してから決める

- 偏り：1つの考え方の型は2割まで。人が死ぬオチにも上限
- 表記：「問題は AI（Claude）で下書きし、作者が確認したものです。プレイ中に AI が文章を生成することはありません」
- 追加：公開後は、まとめて5問ずつ追加（そのたびに AI 対戦を1回だけ回す）
