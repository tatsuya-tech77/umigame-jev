# 問題ごとの画像の指示文

画像は `umigame/static/img/<id>.png` に置く。生成した画像は、そのままではなく
`python3 tools/palette.py 元の画像.png umigame/static/img/<id>.png --width 240` で
白黒ベースの4階調（#f6f4ef / #cfc8b8 / #6b6558 / #1d1b16）のドット絵に変換してから置く。
画像生成AIは色数の指示を守りきれないため、色は変換でそろえる。

## 守ること

- **真相を描かない**。描くのは問題文の場面だけ
- 文字を入れない（値札・看板も読めないように）
- 全部の問題で同じスタイルにする（同じ会話の中で続けて頼む）

## 共通のスタイル（決定：パターン B）

```
昔の白黒ゲーム機のような、単純なドット絵。白黒と灰色だけ、太い輪郭線、陰影はほとんどなし、大きなドット、文字なし、横長 3:2。
構図: 主役の物を1つ大きめに描き、それを置いている台など、場面がわかる最小限の物だけを添える。壁や窓などの背景は無地の白。
人物を描くときは小さなドットのキャラクターで、表情は描かない。
```

（試したもの: A アイコン＝主役だけ → シンプルすぎ／C 部屋全体 → 情報が多い。B に決定）

## 問題ごとの場面

### p001（★1）
```
場面: 薄暗い寝室の枕元。サイドテーブルの上に、針が3時を指すアナログの目覚まし時計。
きちんと整えられたベッド。カーテンは閉じていて、外が昼か夜かはわからないようにしてください。
```

### p002（★3）
```
場面: 家の窓ガラスが割れていて、床にガラスの破片と野球のボールが転がっている。
割れた窓の外に、バットを持った少年3人のシルエット。家の戸口で、女性のシルエットが少年たちに頭を下げている。
部屋の中の様子（台所や家電）は描かないでください。
```

### p003（★2）
```
場面: 静かで薄暗い部屋で、アップライトピアノの前に座る男性の後ろ姿。
弾き終えたところで、両手を鍵盤から少し浮かせている。
聴き手や客席は描かず、部屋はしんと静まり返っている雰囲気で。
```

### p004（★4）
```
場面: リボンのかかったプレゼントの箱に、紐で小さな値札がぶら下がっている（値札の文字は読めないように）。
箱を受け取る女性の手のシルエット。箱の中身は見せないでください。
```

### p005（★3）
```
場面: 朝の駅のホーム。女性がひとり、白線の内側に立っている。手には小さな切符。
ホームに電車が停まっているが、女性は乗らずに見ている。運転席は描かないでください。
両手は体の横に下ろし、切符は体の横で持つ（手を上げると「見送り」のヒントになってしまう）。
```

### classic1（本家ウミガメのスープ。記事・デモ用）
```
場面: 海辺のレストランのテーブルに置かれた、湯気の立つスープの皿とスプーン。皿を大きめに描き、
奥の小さな窓から海の波と水平線が少しだけ見える。人物・ウミガメ・船は描かない。文字やメニュー表も入れない。
```
（遭難や真相につながるものは描かない）
